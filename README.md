# 攀爬架三维编辑器

独立、离线可用的浏览器编辑器，无前端运行依赖，无后端服务。默认模型最高为4根35cm管；140cm为管长合计，未计入接头外壳和插入量。

## 使用

直接用支持WebGL的浏览器打开 `index.html`。手机浏览器对本地文件、下载和本地存储的支持可能不同。

也可启动本地静态预览，需要 Node.js 18或以上、Python 3，无需安装依赖：

```sh
npm run check
npm start
```

打开 http://127.0.0.1:8080 。该命令只提供本地静态文件，不提供远程保存API。

## 功能

- 鼠标拖动旋转、滚轮缩放，右键或Shift拖动平移；手机支持双指缩放和平移。
- 双击不复位；点击“复位”恢复视角，“全图”显示完整模型。
- 爆炸图保持管件长度，向外展开；接头优先命中，并扩大触屏点击范围。
- 编辑35cm、15cm管子，支持45度斜向屋顶示例。
- 根据连接方向匹配接头型号，也可切换兼容朝向。
- 添加管子先预览再确认，预览中切换长度、方向或端点会实时更新，可连续接管。
- 撤销、重做会恢复当时选中的部件；新建空白后直接进入添加管子。
- 改长度先预览再确认，固定端与移动端以A/B标记；已有其他管子不会自动变形。
- 添加方向提前检查，禁用冲突方向并显示原因；手机端保留选中信息。
- 撤销按坐标恢复接头选择；附件显隐也支持撤销、重做。
- 蹦床面、平台、吊环为固定位置的展示附件，不会随自定义管架自动重建。

## 保存与迁移

修改后尝试将草稿保存到当前浏览器的localStorage；刷新或重新打开时自动恢复上次编辑。新版导出HTML带有独立方案标识，刷新时自动恢复该方案自己的草稿；旧版无标识HTML仍优先加载内嵌方案并提供手动恢复入口。存储按页面路径隔离，不同设备、浏览器或文件路径不会自动共享。隐私模式、清理浏览器数据或存储权限限制可能导致草稿丢失。

长期备份使用“保存方案JSON”，之后通过“导入方案”继续编辑；“导出当前方案HTML”可将当前设计与编辑器一起保存。下载文件通常在浏览器设置的下载目录中。更换编辑器版本前，先从旧页面导出JSON，再导入新版。

快捷键：Ctrl/Cmd+Z撤销，Ctrl/Cmd+Shift+Z或Ctrl/Cmd+Y重做，Esc取消预览；输入控件获得焦点时不拦截这些快捷键。

## 目录与维护

- `index.html`：完整界面、WebGL模型、编辑逻辑及默认结构。
- `scripts/check.mjs`：验证HTML中脚本语法、默认嵌入数据以及唯一元素ID。
- `scripts/check-drafts.mjs`：验证保存后刷新恢复、内嵌方案优先及存储异常处理。

源文件沿用CRLF行尾。修改后执行 `npm run check`，并在真实浏览器中回归旋转、选取、预览确认、撤销、导入导出与草稿恢复。语法检查不能代替交互检查。

## 部署边界

可将 `index.html` 发布到静态网站服务。本项目未配置自动发布或GitHub Pages，也没有服务器端存储、用户账号或跨设备同步功能。仓库内不应提交个人草稿、下载文件、密钥或环境配置。

## 使用边界

本编辑器仅检查几何连接，不验证承重、夹困风险或防侧翻。默认结构含按参考图片推定的部分；吊环、蹦床和自定义屋顶不能直接据此承重使用，实际连接和固定需由设备厂家确认。
